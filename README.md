# My Portfolio

Personal portfolio website for Silveri Bandhavi — built with Next.js, TypeScript, and Tailwind CSS.

## Sections

- **Hero** — name and tagline
- **About** — short bio and skills
- **Projects** — three example project cards
- **Contact** — a form (name, email, message) that posts to `/api/contact`

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Editing content

- Name, tagline, bio, skills, and social links: [`src/lib/site-config.ts`](src/lib/site-config.ts)
- Project cards: [`src/data/projects.ts`](src/data/projects.ts)

See [`CLAUDE.md`](CLAUDE.md) for full project context and conventions.
